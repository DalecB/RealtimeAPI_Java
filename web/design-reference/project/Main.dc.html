Foundations & Components

Every screen on this canvas is composed only of the components below. Class names equal component names. Light theme ships first; dark tokens are defined and proven on PipelineStrip. On the screens, the developer layer (the showLabels tweak) names each component, tags the ones that still need an endpoint, and says which numbers are illustrative.
